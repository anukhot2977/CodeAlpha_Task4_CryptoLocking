# 🔐 CodeAlpha Internship - Task 4

## 📌 Project Title: Personal Portfolio (Crypto Locking) Smart Contract

This project is a Personal Portfolio (Crypto Locking) Smart Contract developed using Solidity as part of the Blockchain Internship at CodeAlpha.

The smart contract allows users to deposit Ether with a specific lock-in time. The deposited funds remain securely locked in the contract until the unlock time is reached. Users can only withdraw their funds after the lock period has passed.

This project demonstrates how blockchain technology can be used to create secure time-locked financial systems and portfolio management solutions.

---

## 🚀 Features

✔ Deposit Ether into the smart contract
✔ Set custom lock-in duration for funds
✔ Secure storage of user balances using mappings
✔ Time-lock validation using `block.timestamp`
✔ Prevent early withdrawals
✔ Allow withdrawal only after unlock time
✔ Transparent and secure asset management

---

## 🛠️ Technologies Used

* Solidity
* Remix IDE
* Ethereum Virtual Machine (Remix VM)
* GitHub

---

## 📂 Smart Contract Functions

### 1. deposit()

Allows users to deposit Ether into the smart contract along with a lock duration.

### 2. withdraw()

Allows users to withdraw their deposited Ether only after the lock time has passed.

### 3. getBalance()

Returns the amount of Ether deposited by the user.

### 4. getUnlockTime()

Returns the unlock timestamp for the user’s locked funds.
